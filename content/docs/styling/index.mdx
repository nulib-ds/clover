For Clover's structure alone, or with its spacing, see [Base](/docs/styling/base): its
examples show `base.css` and `spacing.css` on the Viewer and on a layout you compose.

## Stylesheets

| Stylesheet                                                 | What it gives                                                                                            |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `styles.css`, and `templates.css` for Document and Gallery | Clover's whole look: its structure and spacing, and its colors, edges, corners, shadows, type and motion |
| `base.css`, then `spacing.css`                             | Its structure, and its margins, paddings and gaps                                                        |
| `base.css`                                                 | Its structure alone: what shows, where each box sits, how large it is                                    |

Clover's stylesheets sit in `@layer clover`, so your CSS wins without a fight over
specificity. The last two leave the look to you: see [Base](/docs/styling/base).

A recording, a Scene, a map and a vertical slider load their styles with their code, so a
page without them loads none. With `base.css`, they load none of Clover's.

<div data-code-flavor="react">

A map brings MapLibre's stylesheet either way, in a layer after Clover's, unless your page
imports `maplibre-gl/dist/maplibre-gl.css` itself.

Import `styles.css` once, and `templates.css` for Document and Gallery. With no
stylesheet, every component still renders a plain, usable layout.

To load less, import only your components' sheets, in place of `styles.css` and never
beside it: `styles/core.css` first, then the sheet of each component on the page or inside
one (Collection holds `Items`). A page of images with `Root`, `Status`, `Body`, `Position`
and `Items` needs two:

```jsx react
import "@nulib/clover/styles/core.css";
import "@nulib/clover/styles/items.css";
```

| Sheet                          | Components                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `styles/core.css`              | `Root`, `Body` and `Canvas`, `Status`, `Label`, the Primitives                                                              |
| `styles/items.css`             | `Items` and `Position`, and the items in `Collection`, the Panel's Views section and the list under a `Map`                 |
| `styles/items-vertical.css`    | `Items` as a vertical slider, as the `Default` template shows it for a Manifest read down the page                          |
| `styles/panel.css`             | `Panel`, and `About`, `Annotations`, `Collection`, `Contents`, `Download`, `Search` and `Transcript`, in the Panel or alone |
| `styles/media.css`             | Video, sound, `Timeline` and animations, in a `Body` or a `Canvas` too                                                      |
| `styles/scene.css`             | `Scene`, and a 3D model in a `Body`                                                                                         |
| `styles/map.css`               | `Map`, the Panel's Map section, and the map a Canvas opens for a place                                                      |
| `styles/split.css`             | `Split`                                                                                                                     |
| `styles/collection-select.css` | `CollectionSelect`                                                                                                          |
| `styles/default.css`           | The `Default` template, and `PanelPane`, the information panel every template shares                                        |

For Document or Gallery, add `styles/default.css` and `templates.css`. The sheets that load
with their code (`media`, `scene`, `map`, `items-vertical`) need importing only where a
server renders their component, to style its first paint.

</div>

<div data-code-flavor="web-components">

The elements bring Clover's whole look themselves: each adds its styles once, first in
`<head>`, so your rules still win. A map brings MapLibre's stylesheet as MapLibre ships
it, outside any layer, even where your page has its own.

</div>
