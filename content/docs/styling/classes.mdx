# Classes

<div className="docs-lede">
  Select a component in your CSS by the `.clover-*` class on its root, and a
  state by its `data-*` attribute.
</div>

## Classes and states

both flavors.

Add a state to the class to style that state alone:

| Class                                          | State                | Values                                                                                            |
| ---------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------- |
| `.clover-root`                                 | `data-status`        | `idle`, `loading`, `ready`, `error`                                                               |
| `.clover-root`                                 | `data-high-contrast` | Present in [high contrast](/docs/styling/colors#high-contrast), on a component standing alone too |
| `.clover-body`                                 | `data-renderer`      | <span data-code-flavor="both">`canvas`, `timeline`, `scene`, `custom`</span>                      |
| `.clover-canvas`                               | `data-media`         | Its painting body's `type`, lowercased: `image`, `video`, `sound`…                                |
| `.clover-canvas`                               | `data-recording`     | Present when it paints a recording, video or sound, playing or not                                |
| `.clover-canvas`                               | `data-player`        | Present when a sound recording plays alone, as a player                                           |
| `.clover-canvas`                               | `data-animated`      | Present on an animation                                                                           |
| `.clover-canvas`                               | `data-status`        | `loading`, `ready`, `error`                                                                       |
| `.clover-canvas`                               | `data-navigable`     | `true` where it pans and zooms, else `false`                                                      |
| `.clover-canvas`                               | `data-placeholder`   | `true` while its `placeholderCanvas` shows, `false` once opened                                   |
| `.clover-canvas`                               | `data-fullscreen`    | `true`, `false`                                                                                   |
| `.clover-canvas`                               | `data-controls`      | `visible`, `hidden`, where the controls come and go                                               |
| `.clover-items`                                | `data-layout`        | `slider`, `list`, `grid`, `masonry`, `pager`                                                      |
| `.clover-items`                                | `data-orientation`   | `vertical`, on a vertical slider                                                                  |
| `.clover-items`                                | `data-navigation`    | `id`, `homepage`                                                                                  |
| `.clover-pager`                                | `data-direction`     | The resource's `viewingDirection`                                                                 |
| `.clover-pager`                                | `data-size`          | `small`                                                                                           |
| `.clover-panel`                                | `data-layout`        | `tabs`, `accordion`                                                                               |
| `.clover-panel`                                | `data-floating`      | Present when it floats and Escape closes it                                                       |
| `.clover-canvas-button`                        | `data-side`          | `start`, on a PanelToggle that takes the top start corner of the Body's controls                  |
| `.clover-template-panel`                       | `data-side`          | `start`, `end`: the Body's side it sits on ([Helpers](/docs/composing/helpers#panel))             |
| `.clover-template-panel`                       | `data-open`          | `true`, `false`                                                                                   |
| `.clover-template-panes`                       | `data-panel`         | `over`, `beside`: where a template's Panel sits                                                   |
| `.clover-template-default`                     | `data-fill`          | Present when it fills its box (`fill`)                                                            |
| `.clover-template-gallery`                     | `data-height`        | `auto`, `fixed`                                                                                   |
| `.clover-annotations`                          | `data-scope`         | `all`, and none for `view`                                                                        |
| `.clover-content-search`                       | `data-status`        | `idle`, `loading`, `ready`, `error`                                                               |
| `.clover-content-search`, `.clover-transcript` | `data-sticky`        | Present when its field holds at the top as it scrolls                                             |
| `.clover-geomap`                               | `data-status`        | `loading`, `ready`, `error`                                                                       |
| `.clover-split-handle`                         | `data-dragging`      | Present while held                                                                                |
| `.clover-summary`                              | `data-read-more`     | `open`, once Read more shows it whole                                                             |

Here a grid's [`--clover-items-size`](/docs/styling/variables#items-summary-logo-map-and-search):

```css
.clover-items[data-layout="grid"] {
  --clover-items-size: 12rem;
}
```

Set a Canvas's [`--clover-canvas-background`](/docs/styling/variables#the-body) for each
`data-media` the same way.

## Lists in Markdown text

Your CSS [wins over Clover's](/docs/styling#stylesheets), so a reset that strips every list
(`ul, ol { list-style: none; padding: 0 }`, as Tailwind's and many themes' do) strips the
lists in an annotation's or a [`Value`](/docs/primitives/value#markdown)'s Markdown too.
They lose their bullets, numbers and indent, and Safari's VoiceOver stops reading them as
lists. Put them back, indented by
[`--clover-space-l`](/docs/styling/variables#sizes-and-spaces):

```css
:is(.clover-annotations-text, .clover-value) ul {
  list-style: disc;
  padding-inline-start: var(--clover-space-l);
}

:is(.clover-annotations-text, .clover-value) ol {
  list-style: decimal;
  padding-inline-start: var(--clover-space-l);
}
```
