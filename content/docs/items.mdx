## API reference

Inside a `Root`, it lists the resource's views (a spread is one item), and selecting one
goes there: a listbox whose selection follows focus and the arrow keys. On its own, it
lists a Collection's members as links.

<ApiReference elements="clover-items">

| Prop            | Type                                      | Default                         | Description                                                  |
| --------------- | ----------------------------------------- | ------------------------------- | ------------------------------------------------------------ |
| `layout`        | `"slider" \| "list" \| "grid" \| "pager"` | `"slider"`                      | Thumbnails in a row, a column or a grid, or one at a time.   |
| `of`            | `"views" \| "members"`                    | `"views"`                       | In a `Root`: its views, or its Collection's members.         |
| `iiifContent`   | `string \| object`                        | —                               | On its own: a Collection (its members) or a Manifest.        |
| `items`         | `object[]`                                | —                               | On its own: IIIF resources to list as they are.              |
| `navigation`    | `"id" \| "homepage"`                      | `"id"`; `"homepage"` on its own | Select a view, or link to each item's `homepage`.            |
| `onSelect`      | `(item, event) => void`                   | —                               | An item was chosen; on a link, `preventDefault()` stays put. |
| `header`        | `boolean`                                 | `true`                          | On its own: the resource's label, summary and homepage link. |
| `headingLevel`  | `number`                                  | `2`                             | On its own: the header's title level.                        |
| `thumbnailSize` | `number`                                  | `200`                           | Pixels asked for each thumbnail's longer side.               |
| `renderItem`    | `(item, { selected }) => ReactNode`       | —                               | Your own item in place of the figure.                        |
| `request`       | `{ credentials, headers, fetch }`         | The Root's                      | On its own: for every request.                               |
| `language`      | `string`                                  | The reader's                    | On its own: the language to read IIIF text in.               |

</ApiReference>

## Examples

### Grid

Use `layout="grid"` for thumbnails that wrap into rows.

<Example>
<PartDemo part="Items" props={{ layout: "grid" }} body />

```jsx
<Clover.Items layout="grid" />
```

</Example>

### List

Use `layout="list"` for a column, each item's title beside its picture.

<Example>
<PartDemo part="Items" props={{ layout: "list" }} body />

```jsx
<Clover.Items layout="list" />
```

</Example>

### One at a time

Use `layout="pager"` for the count with Previous and Next, and no thumbnails. It steps a
spread at a time through a paged book.

<Example>
<PartDemo part="Items" props={{ layout: "pager" }} body />

```jsx
<Clover.Items layout="pager" />
```

</Example>

### Size

Size the thumbnails with CSS: `--clover-items-height` for a slider's pictures (default
`8rem`), `--clover-items-size` for a grid's columns (`10rem`), `--clover-items-gap`
between them (`1rem`).

<Example>
<PartDemo
  part="Items"
  props={{ style: { "--clover-items-height": "5rem" } }}
  body
/>

```jsx
<Clover.Items style={{ "--clover-items-height": "5rem" }} />
```

</Example>

### A Collection

Give it a Collection on its own, and it lists the members as links to each one's
`homepage`, under the Collection's label and summary.

<Example>
<CollectionItemsDemo />

```jsx
<Clover.Items iiifContent="https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif" />
```

</Example>
