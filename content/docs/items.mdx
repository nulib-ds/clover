## API reference

Inside a `Root`, it lists the resource's views (a spread is one item), and selecting one
goes there: a listbox whose selection follows focus and the arrow keys. On its own, it
lists a Collection's members as links. A Manifest or Collection read right to left
(`viewingDirection`) runs its items leftward, its first on the right, the arrows, the
arrow keys and the pager's steps with it.

## Examples

### Grid

Use `layout="grid"` for thumbnails that wrap into rows.

<Example>
<PartDemo part="Items" props={{ layout: "grid" }} body />

```jsx
<Clover.Items layout="grid" />
```

</Example>

### Masonry

Use `layout="masonry"` for a grid whose pictures keep their own proportions, each packed up
under the one above it. It still reads left to right, row by row, as the arrow keys move.

<Example>
<PartDemo part="Items" props={{ layout: "masonry" }} body />

```jsx
<Clover.Items layout="masonry" />
```

</Example>

### List

Use `layout="list"` for a column, each item's title beside its picture.

<Example>
<PartDemo part="Items" props={{ layout: "list" }} body />

```jsx
<Clover.Items layout="list" />
```

</Example>

### Vertical slider

Use `orientation="vertical"` for a filmstrip beside the Body: a column that fills the
height of what holds it, its pictures as wide as the column, and its arrows at its top and
foot, clear of the pictures. A Manifest read bottom to top runs the column upward, its
first at the foot, Next at the top and the up arrow key stepping forward.

<Example>
<PartDemo
  part="Items"
  props={{ orientation: "vertical", labels: false }}
  body
  side="8rem"
  height={480}
/>

```jsx
<Clover.Root
  iiifContent={url}
  style={{ display: "grid", gridTemplateColumns: "8rem 1fr", height: 480 }}
>
  <Clover.Items orientation="vertical" labels={false} />
  <Clover.Body />
</Clover.Root>
```

</Example>

### One at a time

Use `layout="pager"` for the count with Previous and Next, and no thumbnails. It steps a
spread at a time through a paged book.

<Example>
<PartDemo part="Items" props={{ layout: "pager" }} body />

```jsx
<Clover.Items layout="pager" />
```

</Example>

### Size

Size the thumbnails with CSS: `--clover-items-height` for a slider's pictures (default
`8rem`), `--clover-items-size` for a grid's columns (`10rem`), `--clover-items-gap`
between them (`1rem`). `--clover-items-inset` adds room at a slider's ends (`0`), so its
first and last items rest clear of its arrows.

<Example>
<PartDemo
  part="Items"
  props={{ style: { "--clover-items-height": "5rem" } }}
  body
/>

```jsx
<Clover.Items style={{ "--clover-items-height": "5rem" }} />
```

</Example>

### A Collection

Give it a Collection on its own, and it lists the members as links to each one's
`homepage`, under the Collection's label and summary. Under each member's label is its
summary; `secondary="navDate"` shows its date instead, and `secondary="none"` neither.

<Example>
<CollectionItemsDemo />

```jsx
<Clover.Items iiifContent="https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif" />
```

</Example>
