## API reference

Inside a `Root`, it shows About and each section the resource has data for, or `Tab`s of
your own: one always open, each loaded the first time it opens. Its tabs and accordion
follow WAI-ARIA's patterns. It is as tall as its sections; to scroll it, give the element
around it a height and `overflow-y: auto`, as the templates do. Its other props, and its
`ref`, go to its element.

<ApiReference elements="clover-panel clover-tab clover-panel-toggle clover-about">

### Panel

| Prop            | Type                      | Default   | Description                                                                                                                    |
| --------------- | ------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `layout`        | `"tabs" \| "accordion"`   | `"tabs"`  | A row of tabs, or sections stacked, each under its heading.                                                                    |
| `defaultValue`  | `string`                  | The first | The section open first.                                                                                                        |
| `value`         | `string`                  | —         | The section open, controlled.                                                                                                  |
| `onValueChange` | `(value: string) => void` | —         | A section was opened.                                                                                                          |
| `onClose`       | `() => void`              | —         | A close button, for a panel floating over the page.                                                                            |
| `closeOnEscape` | `boolean`                 | `false`   | Escape closes it too; its close button moves to its inner edge.                                                                |
| `headingLevel`  | `number`                  | `3`       | Its first headings: one below the heading over it.                                                                             |
| `download`      | `boolean`                 | `true`    | A Download button beside About's heading, listing the downloads; `false` leaves them out.                                      |
| `languages`     | `boolean`                 | `true`    | About's heading offers the languages the resource comes in, the whole Root reading in the one chosen; `false` leaves them out. |
| `as`            | element type              | `"aside"` | The element to render.                                                                                                         |
| `children`      | `ReactNode`               | —         | `Tab`s: sections of your own, in place of the defaults.                                                                        |
| `className`     | `string`                  | —         | Added to `clover-panel`.                                                                                                       |

### Tab

One section of a `Panel`: a tab, or a heading in an accordion. It renders nothing itself.

| Prop       | Type        | Default  | Description                                                     |
| ---------- | ----------- | -------- | --------------------------------------------------------------- |
| `value`    | `string`    | Required | Names it, for the panel's `value` and `defaultValue`.           |
| `label`    | `ReactNode` | Required | Its tab's or heading's text. Mark another language with `lang`. |
| `children` | `ReactNode` | —        | What the section shows.                                         |

### PanelToggle

A round button that shows and hides the panel. As a child of `Body`, it sits among the
Canvas's controls.

| Prop           | Type                      | Default  | Description                            |
| -------------- | ------------------------- | -------- | -------------------------------------- |
| `open`         | `boolean`                 | Required | Whether the panel is showing.          |
| `onOpenChange` | `(open: boolean) => void` | Required | Called with `!open` when pressed.      |
| `controls`     | `string`                  | —        | The panel's `id`, for `aria-controls`. |

### About

The panel's first section, and a part of its own: the resource's label and thumbnail, summary,
metadata, required statement, its date (`navDate`, in the reader's language), provider, rights,
homepage, see also, downloads and address. For a Canvas shown
on its own, it starts with the Manifest the Canvas is part of.

| Prop            | Type      | Default | Description                                                                                                                                                       |
| --------------- | --------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `canvasSummary` | `boolean` | `false` | The current Canvas's summary too, before the resource's.                                                                                                          |
| `download`      | `boolean` | `true`  | Alone, outside a Panel: the downloads, Download's links, in a section of their own. In a Panel, its heading's Download button lists them.                         |
| `languages`     | `boolean` | `true`  | Alone, outside a Panel: the languages the resource comes in, over what About says, the whole Root reading in the one chosen. In a Panel, its heading offers them. |
| `headingLevel`  | `number`  | `3`     | Its titles: the label, Rights, Homepage and the rest.                                                                                                             |
| `label`         | `boolean` | `true`  | The resource's label first, as a heading.                                                                                                                         |
| `thumbnail`     | `boolean` | `true`  | The resource's thumbnail, small, beside the label.                                                                                                                |
| `className`     | `string`  | —       | Added to `clover-about`.                                                                                                                                          |

</ApiReference>

## Examples

### Sections

With no `Tab`s, it shows [About](#about), then each section the resource has data for:
Views (a content state's targets, where it names two or more, as
[Items](/docs/items) lists them, with steps between them),
[Collection](/docs/collection), [Contents](/docs/contents), [Search](/docs/search),
[Map](/docs/map), [Transcript](/docs/transcript) and [Annotations](/docs/annotations).
This newspaper has a Content Search service, and its OCR as annotations, which a search
finds in.

### Tabs or accordion

Use `layout="accordion"` to stack the sections, each opened by its heading, as the
[templates](/docs/viewer#panel-layout) do. In a box that scrolls, the headings stay in
sight, at its top and its foot.

<Example>
<PartDemo
  part="Panel"
  props={{ layout: "accordion", headingLevel: 4 }}
  body
  box="24rem"
/>

```jsx
<Clover.Panel layout="accordion" />
```

</Example>

### The open section

Use `defaultValue` to choose the section open first, or `value` and `onValueChange` to
control it. The default sections are `about`, `targets`, `collection`, `contents`, `search`, `map`,
`transcript` and `annotations`. A search started outside the Search section (the Root's
`searchQuery`, or your own `clover.search()`) opens it, ahead of `defaultValue`, so its
hits come with their list. Focus stays where it is, and a Panel that is shut stays shut
until the reader opens it, on Search. A `value` you control is left as you set it. This film opens on its chapters.

<Example>
<PartDemo
  part="Panel"
  resource="footage"
  props={{ defaultValue: "contents", headingLevel: 4 }}
  body
  box="24rem"
/>

```jsx
<Clover.Panel defaultValue="contents" />
```

</Example>

### Languages

Where what a resource says of itself comes in several languages, About's heading offers
them, shown whichever section is open, and every part in the Root reads IIIF text in the
one chosen, a title over it as About. It starts in the Root's `language`, which a page
sets to read in its own, here French, else in the reader's. A reader's choice lasts until
the page gives the Root another `language`. This painting is described in English and
French.

<Example>

### Sections of your own

Give it `Tab`s, and they are its sections, in their order. Each holds Clover's parts or a
component of your own that reads the Root through hooks. Give the parts in them the
heading level the panel would: its own in tabs, one below it in an accordion.

```jsx
function PageNotes({ notes }) {
  const canvas = Clover.useActiveCanvas();
  return <p>{notes[canvas?.id] ?? "No notes for this page."}</p>;
}

<Clover.Panel>
  <Clover.Tab value="about" label="About">
    <Clover.About />
  </Clover.Tab>
  <Clover.Tab value="notes" label="Notes">
    <PageNotes notes={notes} />
  </Clover.Tab>
</Clover.Panel>;
```

```html twin
<clover-panel>
  <clover-tab value="about" label="About">
    <clover-about></clover-about>
  </clover-tab>
  <clover-tab value="notes" label="Notes">
    <p id="page-notes"></p>
  </clover-tab>
</clover-panel>

<script type="module">
  const root = document.querySelector("clover-root");
  const shown = document.getElementById("page-notes");
  const show = () => {
    const canvas = root.clover.activeCanvas();
    shown.textContent = notes[canvas?.id] ?? "No notes for this page.";
  };
  const start = () => {
    show();
    root.clover.subscribe(show);
  };
  if (root.clover) start();
  else root.addEventListener("clover-ready", start, { once: true });
</script>
```

### Showing and hiding it

`PanelToggle` shows and hides it: name the panel in its `controls`, and hide the panel with
`hidden`. A panel floating over the page also takes `onClose`, for a close button, and
`closeOnEscape`; move focus into it as it opens.

```jsx
function Layout({ url }) {
  const [open, setOpen] = React.useState(true);
  return (
    <Clover.Root iiifContent={url}>
      <Clover.Body>
        <Clover.PanelToggle
          open={open}
          onOpenChange={setOpen}
          controls="panel"
        />
      </Clover.Body>
      <Clover.Panel id="panel" hidden={!open} />
    </Clover.Root>
  );
}
```

```html twin
<!-- The toggle follows the panel's own hidden: write hidden on it to start it shut. -->
<clover-root
  iiif-content="https://iiif.io/api/cookbook/recipe/0009-book-1/manifest.json"
>
  <clover-body>
    <clover-panel-toggle controls="panel"></clover-panel-toggle>
  </clover-body>
  <clover-panel id="panel"></clover-panel>
</clover-root>
```
