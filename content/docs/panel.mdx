## API Reference

Inside a `Root`, it shows About and each section the resource has data for, or `Tab`s of
your own: one always open, each loaded the first time it opens. Its tabs and accordion
follow WAI-ARIA's patterns. It is as tall as its sections; to scroll it, give the element
around it a height and `overflow-y: auto`, as the templates do. Its other props, and its
`ref`, go to its element.

### Panel

| Prop            | Type                      | Default   | Description                                                     |
| --------------- | ------------------------- | --------- | --------------------------------------------------------------- |
| `layout`        | `"tabs" \| "accordion"`   | `"tabs"`  | A row of tabs, or sections stacked, each under its heading.     |
| `defaultValue`  | `string`                  | The first | The section open first.                                         |
| `value`         | `string`                  | —         | The section open, controlled.                                   |
| `onValueChange` | `(value: string) => void` | —         | A section was opened.                                           |
| `onClose`       | `() => void`              | —         | A close button, for a panel floating over the page.             |
| `closeOnEscape` | `boolean`                 | `false`   | Escape closes it too; its close button moves to its inner edge. |
| `headingLevel`  | `2 \| 3 \| 4 \| 5 \| 6`   | `3`       | Its first headings: one below the heading over it.              |
| `as`            | element type              | `"aside"` | The element to render.                                          |
| `children`      | `ReactNode`               | —         | `Tab`s: sections of your own, in place of the defaults.         |
| `className`     | `string`                  | —         | Added to `clover-panel`.                                        |

### Tab

One section of a `Panel`: a tab, or a heading in an accordion. It renders nothing itself.

| Prop       | Type        | Default  | Description                                                     |
| ---------- | ----------- | -------- | --------------------------------------------------------------- |
| `value`    | `string`    | Required | Names it, for the panel's `value` and `defaultValue`.           |
| `label`    | `ReactNode` | Required | Its tab's or heading's text. Mark another language with `lang`. |
| `children` | `ReactNode` | —        | What the section shows.                                         |

### PanelToggle

A round button that shows and hides the panel. As a child of `Content`, it sits among the
Canvas's controls.

| Prop           | Type                      | Default  | Description                            |
| -------------- | ------------------------- | -------- | -------------------------------------- |
| `open`         | `boolean`                 | Required | Whether the panel is showing.          |
| `onOpenChange` | `(open: boolean) => void` | Required | Called with `!open` when pressed.      |
| `controls`     | `string`                  | —        | The panel's `id`, for `aria-controls`. |

### About

The panel's first section, and a part of its own: the resource's summary, metadata,
required statement, rights, homepage, see also, downloads and address. For a Canvas shown
on its own, it starts with the Manifest the Canvas is part of.

| Prop            | Type                    | Default | Description                                              |
| --------------- | ----------------------- | ------- | -------------------------------------------------------- |
| `canvasSummary` | `boolean`               | `false` | The current Canvas's summary too, before the resource's. |
| `headingLevel`  | `2 \| 3 \| 4 \| 5 \| 6` | `3`     | Its titles: Rights, Homepage and the rest.               |
| `className`     | `string`                | —       | Added to `clover-about`.                                 |

## Examples

### Sections

With no `Tab`s, it shows [About](#about), then each section the resource has data for:
[Collection](/docs/collection), [Contents](/docs/contents), [Search](/docs/search),
[Map](/docs/map), [Transcript](/docs/transcript) and [Annotations](/docs/annotations).
This newspaper has a Content Search service, and its OCR as annotations.

<PartDemo

  content
  box="24rem"

```jsx
<Clover.Root iiifContent="https://nulib-ds.github.io/clover/mocks/content-search/manifest.json">
  <Clover.Content />
  <div style={{ height: "24rem", overflowY: "auto" }}>
```

### Tabs or accordion

Use `layout="accordion"` to stack the sections, each opened by its heading, as the
[templates](/docs/viewer#panel-layout) do. In a box that scrolls, the headings stay in
sight, at its top and its foot.

<Example>
<PartDemo
  part="Panel"
  props={{ layout: "accordion", headingLevel: 4 }}
  content
  box="24rem"
/>

```jsx
<Clover.Panel layout="accordion" />
```

</Example>

### The open section

Use `defaultValue` to choose the section open first, or `value` and `onValueChange` to
control it. The default sections are `about`, `collection`, `contents`, `search`, `map`,
`transcript` and `annotations`. This film opens on its chapters.

<Example>
<PartDemo
  part="Panel"
  resource="footage"
  props={{ defaultValue: "contents", headingLevel: 4 }}
  content
  box="24rem"
/>

```jsx
<Clover.Panel defaultValue="contents" />
```

</Example>

### Sections of your own

Give it `Tab`s, and they are its sections, in their order. Each holds Clover's parts or a
component of your own that reads the Root through hooks. Give the parts in them the
heading level the panel would: its own in tabs, one below it in an accordion.

```jsx
function PageNotes({ notes }) {
  const canvas = Clover.useActiveCanvas();
  return <p>{notes[canvas?.id] ?? "No notes for this page."}</p>;
}

<Clover.Panel>
  <Clover.Tab value="about" label="About">
    <Clover.About />
  </Clover.Tab>
  <Clover.Tab value="notes" label="Notes">
    <PageNotes notes={notes} />
  </Clover.Tab>
</Clover.Panel>;
```

### Showing and hiding it

`PanelToggle` shows and hides it: name the panel in its `controls`, and hide the panel with
`hidden`. A panel floating over the page also takes `onClose`, for a close button, and
`closeOnEscape`; move focus into it as it opens.

```jsx
function Layout({ url }) {
  const [open, setOpen] = React.useState(true);
  return (
    <Clover.Root iiifContent={url}>
      <Clover.Content>
        <Clover.PanelToggle
          open={open}
          onOpenChange={setOpen}
          controls="panel"
        />
      </Clover.Content>
      <Clover.Panel id="panel" hidden={!open} />
    </Clover.Root>
  );
}
```
