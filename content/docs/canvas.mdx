## API reference

Draws the Canvases you hand it, or loads one itself (`iiifContent`), with
WebGL2, else Canvas2D. Inside a `Root`, given nothing to draw, it shows the Root's current
view. It fills its parent, so give the parent a height.

It is experimental: its API may change in any release. A plain wheel scrolls the page,
unless `options.gestures.scrollToZoom` is on.

### Collapse controls

The controls stay on one row: the view's first (zoom, rotation, reset and full screen),
then the Canvas's own (its place, annotations and About). Collapsing the view's controls
behind one button keeps that row to the room it has, on a phone or in a narrow column, and
leaves more of the screen to the image or recording. `collapseControls` says when: by
default, <span data-code-flavor="both">`auto`</span>, only where the row cannot hold them
all; or <span data-code-flavor="both">`always`</span>, however wide the Body is, for the
most room around the media.

Collapsed, they wait behind "Expand viewer controls", in their place. Pressed, it opens a
tray of them beside the rest, with arrows at its ends where it is too narrow for them all,
and pressed again, "Collapse viewer controls", it closes.

### Video and sound

A Canvas of video or sound plays in Clover's own transport, with the captions it carries.
Each WebVTT file is offered for what its annotation `provides`:
`closedCaptions` as captions, `subtitles` or `translation` as subtitles, and a
`transcript` alone only in the [Transcript](/docs/transcript). A file that provides
nothing is captions.

### Annotations on a recording's time

An annotation on a stretch of a recording (`#t=`) shows among its captions while that
stretch plays; one with a region too (`xywh=…&t=…`) follows what it marks, frame by frame.
Picking one, from the annotations menu or a list beside it, goes to its time.

### Canvas handles and callbacks

`onReady` hands you the Canvas's handle, to drive the view from controls of your own. Here
each of the page's buttons calls it: `zoomBy` zooms by a step, or to a level, as world
units are the first image's pixels and a camera `zoom` of 1 is the image at 100%;
`setRotation` turns it a quarter turn; `home` goes back to the whole image, upright; and
`fitBounds` frames an `xywh` region, the map's title to start. Each takes whether to
animate, which Animate sets here; where the system asks for reduced motion, the view
never animates.

<div data-code-flavor="react">

`onViewportChange` reports the region in view as it moves, in the same pixels: an `xywh`
you can hand `fitBounds` again.

</div>

<div data-code-flavor="web-components">

The handle's `viewport` event (`handle.on("viewport", …)`) says when the view moves, and
`handle.getBounds()` gives the region in view, in the same pixels: an `xywh` you can hand
`fitBounds` again.

</div>

```jsx
import { useEffect, useRef, useState } from "react";
import * as Clover from "@nulib/clover";

// World units are the image's pixels, so a camera zoom of 1 is the image at 100%.
const LEVELS = [0.25, 0.5, 1];

export default function MapControls() {
  const [canvas, setCanvas] = useState(null);
  const [animate, setAnimate] = useState(true);
  const [region, setRegion] = useState("4200,1300,2400,1300");
  const [invalid, setInvalid] = useState(false);
  const [inView, setInView] = useState("");
  const settle = useRef();
  useEffect(() => () => clearTimeout(settle.current), []);

  const zoomTo = (level) =>
    canvas.zoomBy(level / canvas.getCamera().zoom, undefined, animate);
  const rotate = (degrees) =>
    canvas.setRotation(canvas.getRotation() + degrees, !animate);
  const goTo = (event) => {
    event.preventDefault();
    const [x, y, width, height] = region
      .replace("xywh=", "")
      .split(",")
      .map(Number);
    const valid =
      [x, y, width, height].every(Number.isFinite) && width > 0 && height > 0;
    setInvalid(!valid);
    if (valid) canvas.fitBounds({ x, y, width, height }, !animate);
  };

  return (
    <>
      <div style={{ height: 450 }}>
        <Clover.Canvas
          src="https://iiif.dc.library.northwestern.edu/iiif/3/2fb1e81a-9e24-420c-b224-0bfd6a279baf"
          isTiledImage
          label="Map of the Township of Evanston, Cook County, Illinois"
          onReady={setCanvas}
          onViewportChange={({ x, y, width, height }) => {
            // Once the view settles: the readout is a live region, and the view
            // moves every frame.
            clearTimeout(settle.current);
            settle.current = setTimeout(
              () => setInView([x, y, width, height].map(Math.round).join(",")),
              250,
            );
          }}
        />
      </div>
      <button
        type="button"
        disabled={!canvas}
        onClick={() => canvas.zoomBy(2, undefined, animate)}
      >
        Zoom in
      </button>
      <button
        type="button"
        disabled={!canvas}
        onClick={() => canvas.zoomBy(0.5, undefined, animate)}
      >
        Zoom out
      </button>
      <div role="group" aria-labelledby="zoom-to">
        <span id="zoom-to">Zoom to</span>
        {LEVELS.map((level) => (
          <button
            key={level}
            type="button"
            disabled={!canvas}
            aria-label={`Zoom to ${level * 100}%`}
            onClick={() => zoomTo(level)}
          >
            {level * 100}%
          </button>
        ))}
      </div>
      <button type="button" disabled={!canvas} onClick={() => rotate(-90)}>
        Rotate left
      </button>
      <button type="button" disabled={!canvas} onClick={() => rotate(90)}>
        Rotate right
      </button>
      <button
        type="button"
        disabled={!canvas}
        onClick={() => canvas.home(!animate)}
      >
        Reset
      </button>
      <form onSubmit={goTo}>
        <label htmlFor="region">Region (xywh)</label>
        <input
          id="region"
          value={region}
          aria-invalid={invalid}
          aria-describedby={invalid ? "region-error" : undefined}
          onChange={(event) => {
            setRegion(event.target.value);
            setInvalid(false);
          }}
        />
        <button disabled={!canvas}>Go to region</button>
        {invalid && (
          <p id="region-error">Give four numbers: x, y, width and height.</p>
        )}
      </form>
      <label>
        <input
          type="checkbox"
          checked={animate}
          onChange={(event) => setAnimate(event.target.checked)}
        />
        Animate
      </label>
      <output>{canvas ? `In view: xywh=${inView}` : "Loading…"}</output>
    </>
  );
}
```

<script type="module">
  const map = document.getElementById("map");
  const animate = document.getElementById("animate");
  const region = document.getElementById("region");
  const error = document.getElementById("region-error");
  const inView = document.getElementById("in-view");
  let settle;

  map.addEventListener("clover-ready", ({ detail: { handle } }) => {
    handle.on("viewport", () => {
      // Once the view settles: the readout is a live region, and the view moves
      // every frame.
      clearTimeout(settle);
      settle = setTimeout(() => {
        const { x, y, width, height } = handle.getBounds();
        const xywh = [x, y, width, height].map(Math.round).join(",");
        inView.value = `In view: xywh=${xywh}`;
      }, 250);
    });
  });

  // World units are the image's pixels, so a camera zoom of 1 is the image at 100%.
  document.getElementById("controls").addEventListener("click", (event) => {
    const button = event.target.closest("button");
    const handle = map.handle;
    if (!button || !handle) return;
    const { zoom, level, turn } = button.dataset;
    const motion = animate.checked;
    if (zoom) handle.zoomBy(Number(zoom), undefined, motion);
    if (level)
      handle.zoomBy(Number(level) / handle.getCamera().zoom, undefined, motion);
    if (turn) handle.setRotation(handle.getRotation() + Number(turn), !motion);
    if ("reset" in button.dataset) handle.home(!motion);
  });

  document.getElementById("go").addEventListener("submit", (event) => {
    event.preventDefault();
    const [x, y, width, height] = region.value
      .replace("xywh=", "")
      .split(",")
      .map(Number);
    const valid =
      [x, y, width, height].every(Number.isFinite) && width > 0 && height > 0;
    region.setAttribute("aria-invalid", String(!valid));
    error.textContent = valid
      ? ""
      : "Give four numbers: x, y, width and height.";
    if (valid) map.handle?.fitBounds({ x, y, width, height }, !animate.checked);
  });
</script>

### Canvas or Body

In a layout, place [`Body`](/docs/body) rather than `Canvas`: it draws the Root's
view with this Canvas, and adds a height, your renderers, and the loading mark while the
Root loads. A `Canvas` alone in a `Root` shows the same view, without them.

```jsx
<Clover.Root iiifContent={url}>
  <Clover.Body />
</Clover.Root>
```

## Previous versions

[Clover 3.x › Image](/docs/deprecated-versions/image)

- `Canvas` replaces `Image`, and the Viewer's player for video and sound.
- `body`, `src`, `label` and `instanceId` carry over.
- `openSeadragonCallback` is `onReady`, which hands you a handle.
- `openSeadragonConfig` is `options`.
