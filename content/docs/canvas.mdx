## API reference

Draws the Presentation 4 Canvases you hand it, or loads one itself (`iiifContent`), with
WebGL2, else Canvas2D. Inside a `Root`, given nothing to draw, it shows the Root's current
view. It fills its parent, so give the parent a height.

It is experimental: its API may change in any release. A plain wheel scrolls the page,
unless `options.gestures.scrollToZoom` is on.

| Prop                     | Type                                                                       | Default                            | Description                                                                                                                     |
| ------------------------ | -------------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `iiifContent`            | `string \| object`                                                         | —                                  | A Canvas to load and draw, or a Manifest's first: URL or JSON.                                                                  |
| `canvases`               | `object[]`                                                                 | The Root's view                    | Presentation 4 Canvases, drawn together; `toPresentation4()` upgrades older ones.                                               |
| `body`                   | `object \| object[]`                                                       | —                                  | IIIF painting bodies to draw; they win over `src`.                                                                              |
| `src`                    | `string \| string[]`                                                       | —                                  | Image URLs, or image services with `isTiledImage`.                                                                              |
| `isTiledImage`           | `boolean`                                                                  | `false`                            | Read each `src` as an image service: its base URI or `info.json`.                                                               |
| `viewingDirection`       | `"left-to-right" \| "right-to-left" \| "top-to-bottom" \| "bottom-to-top"` | `"left-to-right"`                  | How several Canvases line up; in a `Root`, the Manifest's.                                                                      |
| `label`                  | language map or `string`                                                   | The Canvas's label                 | The viewport's accessible name.                                                                                                 |
| `language`               | `string`                                                                   | The reader's, or the Root's        | The language to read labels, Choices and annotations in.                                                                        |
| `controls`               | `boolean \| { zoom, fullPage, rotation, reset, annotations, information }` | `true`                             | All of Clover's controls, none, or all but those set `false`.                                                                   |
| `navigator`              | `boolean`                                                                  | `false`                            | An overview of the whole image, to press or drag in.                                                                            |
| `placeholder`            | `boolean`                                                                  | `true`                             | Open on the Canvas's `placeholderContainer`, where it has one.                                                                  |
| `options`                | `object`                                                                   | —                                  | `backend`, `gestures`, `maxZoomPixelRatio`, `minZoomImageRatio`, `animationTime`, `hideDelay`, `animation`, `media`, `request`. |
| `controlButtons`         | `object`                                                                   | —                                  | Components of your own for `zoomIn`, `zoomOut`, `fullPage`, `rotateRight`, `rotateLeft`, `reset`, `choice`.                     |
| `onReady`                | `(handle: CanvasHandle) => void`                                           | —                                  | Once laid out, a handle to zoom, pan and turn it.                                                                               |
| `onViewportChange`       | `(bounds: { x, y, width, height }) => void`                                | —                                  | The region in view, at most once a frame.                                                                                       |
| `annotations`            | `{ annotation, targetIndex, pageLabel?, pageId? }[]`                       | The loaded Canvas's, or the Root's | Hotspots on regions, points and shapes; whole-Canvas ones go to its information.                                                |
| `hiddenPages`            | `string[]`                                                                 | —                                  | AnnotationPages (`pageId`) not drawn; its menu still lists them.                                                                |
| `onPageVisibilityChange` | `(pageIds: string[], visible: boolean) => void`                            | —                                  | The reader hid pages, or showed them, from the menu.                                                                            |
| `selectedAnnotation`     | `string \| null`                                                           | —                                  | The picked annotation, controlled; `null` picks none.                                                                           |
| `onAnnotationSelect`     | `(id: string \| null) => void`                                             | —                                  | A hotspot or the menu picked one, or `null` let it go.                                                                          |
| `highlightedAnnotation`  | `string \| null`                                                           | —                                  | One to highlight, as hovering it in a list does.                                                                                |
| `onAnnotationActive`     | `(id: string \| null) => void`                                             | —                                  | The hotspot hovered or focused, or `null`.                                                                                      |
| `onAnnotationLink`       | `(link: { id, canvasId?, manifestId? }) => void`                           | —                                  | A linking hotspot was pressed; in a `Root` or with `iiifContent`, followed for you.                                             |
| `animateAnnotations`     | `boolean`                                                                  | `false`                            | Glide to a picked annotation, rather than cut to it.                                                                            |
| `chapters`               | `{ id?, label, lang?, start, end? }[]`                                     | The Ranges, in a `Root`            | Chapters of the recording, on its seek bar and in a menu.                                                                       |
| `highlightedChapter`     | `string \| null`                                                           | —                                  | A chapter (`id`) to draw out on the seek bar.                                                                                   |
| `onChapterHighlight`     | `(id: string \| null) => void`                                             | —                                  | The chapter under the pointer on the seek bar, or `null`.                                                                       |
| `caption`                | `string \| null`                                                           | —                                  | The caption file (`id`) to show while captions are on.                                                                          |
| `onCaptionChange`        | `(caption: { id, language? } \| null) => void`                             | —                                  | The reader chose a caption file, or Off (`null`).                                                                               |
| `onMediaElement`         | `(element: HTMLVideoElement \| null) => void`                              | —                                  | The recording's element, for a transcript of your own.                                                                          |
| `onEnded`                | `() => void`                                                               | —                                  | Playback reached the end: a cue to move on.                                                                                     |
| `manifestId`             | `string`                                                                   | —                                  | The Canvases' Manifest: a new one clears the Canvas at once.                                                                    |
| `instanceId`             | `string`                                                                   | —                                  | A stable id; a new one remounts the renderer.                                                                                   |
| `className`              | `string`                                                                   | —                                  | Added to `clover-canvas`, on its `figure`.                                                                                      |
| `children`               | `ReactNode`                                                                | —                                  | Your own controls, after Clover's.                                                                                              |

## Examples

### Images

Use `src` for images that are not on a Canvas: plain URLs, or IIIF image services with
`isTiledImage`, tiled from their `info.json`.

<Example>
<div style={{ height: 420 }}>
  <CloverCanvas
    src="https://iiif.dc.library.northwestern.edu/iiif/3/bcb98b9f-4c44-4fd0-bfa9-673fb904a2b1"
    isTiledImage
    label="The Vanishing Race - Navaho"
  />
</div>

```jsx
<Clover.Canvas
  src="https://iiif.dc.library.northwestern.edu/iiif/3/bcb98b9f-4c44-4fd0-bfa9-673fb904a2b1"
  isTiledImage
  label="The Vanishing Race - Navaho"
/>
```

</Example>

### Several Canvases

Hand it the Canvases to show together, a spread say; which to show, and moving between
them, is yours. `groupViews` reads a Manifest's `behavior` as the Viewer does.

<Example>
<CanvasRecipe
  id="paged"
  iiifContent="https://nulib-ds.github.io/clover/mocks/paged/manifest.json"
/>

```jsx
const manifest = await Clover.toPresentation4(json);
const views = Clover.groupViews(
  manifest.items,
  Clover.resolveBehavior(manifest.behavior),
);

<Clover.Canvas
  canvases={views[view].map((index) => manifest.items[index])}
  label={manifest.label}
/>;
```

</Example>

### Annotations on a recording's time

An annotation on a stretch of a recording (`#t=`) shows among its captions while that
stretch plays; one with a region too (`xywh=…&t=…`) follows what it marks, frame by frame.
Picking one, from the annotations menu or a list beside it, goes to its time.

<Example>
<div style={{ height: 420 }}>
  <CloverCanvas iiifContent="https://nulib-ds.github.io/clover/mocks/rudolf-hess-nuremberg/manifest.json" />
</div>

```jsx
<Clover.Canvas iiifContent="https://nulib-ds.github.io/clover/mocks/rudolf-hess-nuremberg/manifest.json" />
```

</Example>

### Driving it

`onReady` hands you a handle (`zoomBy`, `panBy`, `rotateBy`, `home`, `fitBounds` and more) to
drive the view from controls of your own, and `onViewportChange` reports the region in view.

<Example>
<CanvasHandleDemo
  src="https://iiif.dc.library.northwestern.edu/iiif/3/2fb1e81a-9e24-420c-b224-0bfd6a279baf"
  isTiledImage
  label="Map of the Township of Evanston, Cook County, Illinois"
/>

```jsx
const canvas = useRef(null);

<Clover.Canvas
  src={service}
  isTiledImage
  label={label}
  onReady={(handle) => (canvas.current = handle)}
  onViewportChange={(bounds) => setRegion(bounds)}
/>
<button onClick={() => canvas.current.zoomBy(2)}>Zoom in</button>
```

</Example>

### Canvas or Content

In a layout, place [`Content`](/docs/content) rather than `Canvas`: it draws the Root's
view with this Canvas, and adds a height, your renderers, and the loading mark while the
Root loads. A `Canvas` alone in a `Root` shows the same view, without them.

```jsx
<Clover.Root iiifContent={url}>
  <Clover.Content />
</Clover.Root>
```
