## API reference

<ApiReference elements="clover-collection clover-collection-select">

### Collection

Inside a `Root`, it shows the Collection the Manifest was opened from, or else the first
it is `partOf`, fetched as the part first shows: its label, summary and members (each with
its date, its `navDate`, and its summary under its label, where it gives them), then its
homepage and address. Choosing a member shows it. Its other props, and its `ref`, go to
its element.

| Prop           | Type     | Default | Description                                               |
| -------------- | -------- | ------- | --------------------------------------------------------- |
| `headingLevel` | `number` | `3`     | Its headings' level, one below the heading it sits under. |
| `className`    | `string` | —       | Added to `clover-about clover-collection`.                |

### CollectionSelect

Inside a `Root`, it is a menu of the Collection's members, labeled by the Collection:
choosing a Manifest shows it, and choosing a Collection enters it. By keyboard, the arrows
move through the members and Enter shows one; Escape, or leaving the menu, takes the step
back. It renders nothing without a Collection of two or more. Its other props, and its
`ref`, go to its element.

| Prop        | Type                   | Default | Description                                           |
| ----------- | ---------------------- | ------- | ----------------------------------------------------- |
| `onChange`  | `(id: string) => void` | —       | A member was chosen: its `id`, before the Root moves. |
| `className` | `string`               | —       | Added to `clover-collection-select`.                  |

</ApiReference>

## Examples

### A Manifest's Collection

Given a Manifest, it fetches the first Collection the Manifest is `partOf`: here,
Northwestern's bicycle catalogs, in a box that scrolls.

<Example>
<PartDemo
  part="Collection"
  props={{
    headingLevel: 4,
    style: { maxHeight: "24rem", overflowY: "auto" },
  }}
  body
/>

```jsx {3}
<Clover.Root iiifContent="https://clover.iiif.library.northwestern.edu/mocks/paged/manifest.json">
  <Clover.Body />
  <Clover.Collection style={{ maxHeight: "24rem", overflowY: "auto" }} />
</Clover.Root>
```

</Example>

### A menu of members

Use `CollectionSelect` for a menu of the members, to move between them.

<Example>
<PartDemo part="CollectionSelect" resource="collection" body />

```jsx {3}
<Clover.Root iiifContent="https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif">
  <Clover.Body />
  <Clover.CollectionSelect />
</Clover.Root>
```

</Example>

### In the Viewer

The Viewer's Panel shows it as its Collection section, for a Manifest opened from a
Collection or `partOf` one.

<ViewerExample resource="https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif">

```jsx
<Viewer iiifContent="https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif" />
```

</ViewerExample>
