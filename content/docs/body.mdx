## API reference

Draws the Root's current view with [`Canvas`](/docs/canvas), or with a renderer of yours
that claims it, in a box as tall as `--clover-body-height`, `60vh` by default. It works
only inside a `Root`. Its other props are [Canvas's](/docs/canvas#api-reference), and go to
the Canvas, but for what to draw, which comes from the Root; its label, annotations,
chapters and language do too, unless you pass your own.

While the Root loads, it is `aria-busy` and shows Clover's loading mark along its top
edge; `<Clover.Status loading={false} />` announces it. The table of contents is
[`Contents`](/docs/contents).

<ApiReference elements="clover-body">

| Prop        | Type                  | Default    | Description                                                |
| ----------- | --------------------- | ---------- | ---------------------------------------------------------- |
| `renderers` | `BodyRenderer[]`      | The Root's | Components of yours that draw the views they claim.        |
| `style`     | `React.CSSProperties` | —          | On its box, merged over its inline `height`.               |
| `className` | `string`              | —          | Added to `clover-body`.                                    |
| `children`  | `ReactNode`           | —          | Controls after Clover's own, or the renderer's `children`. |

</ApiReference>

## Examples

### Height

Set `--clover-body-height` on it, or on anything around it: `100%` fills a parent with
a height of its own.

<Example>
<PartDemo
  part="Body"
  props={{ style: { "--clover-body-height": "16rem" } }}
/>

```jsx
<Clover.Body style={{ "--clover-body-height": "16rem" }} />
```

</Example>

### Controls

Use `controls` to choose Clover's controls: `false` for none, or an object that leaves some
out.

<Example>
<PartDemo
  part="Body"
  props={{ controls: { rotation: false } }}
  resource="page-transcript"
/>

```jsx
<Clover.Body controls={{ rotation: false }} />
```

</Example>

### Navigator

Use `navigator` for an overview of the whole image, in the top left, to press or drag in.

<Example>
<PartDemo
  part="Body"
  props={{ navigator: true }}
  resource="page-transcript"
/>

```jsx
<Clover.Body navigator />
```

</Example>

### Controls of your own

Children join the Canvas's controls, after Clover's, and stay where Clover's are left out:
over a placeholder, or a lone recording. Name each one as Clover's are named
([Controls of your own](/docs/composing#controls-of-your-own)).

```jsx
<Clover.Body>
  <Clover.PanelToggle open={open} onOpenChange={setOpen} controls="panel" />
</Clover.Body>
```

```html twin
<!-- The toggle shows the panel while the panel is not hidden: hide it to start it shut. -->
<clover-body>
  <clover-panel-toggle controls="panel"></clover-panel-toggle>
</clover-body>
```

### Renderers of your own

Give `renderers` to `Body`, or to the `Root` for every `Body` in it, and a view that
one claims, by Canvas id, painting `format` or a `match` test, is drawn by your component
([Renderers of your own](/docs/composing#renderers-of-your-own)).

```jsx
const renderers = [{ format: ["model/gltf-binary"], component: ModelViewer }];

<Clover.Body renderers={renderers} />;
```

```html twin
<clover-body></clover-body>

<script type="module">
  document.querySelector("clover-body").renderers = [
    {
      format: ["model/gltf-binary"],
      render(container, { bodies }) {
        const model = document.createElement("model-viewer");
        model.setAttribute("src", bodies[0].id);
        container.append(model);
      },
    },
  ];
</script>
```
