## Install

The Viewer and its parts are React components, and custom elements for a page without
React: a CMS template, a static site, an exhibit page. Choose yours, and every example in
these docs is written that way.

<InstallGuide>
<InstallWay way="react">
<div className="docs-steps">

### Install the package

```bash
npm install @nulib/clover
```

React 18 and 19 are supported.

### Install the package

```bash
npm install @nulib/clover
```

### Import the elements

Once, anywhere on the page. The elements bring their own styles, so there is no
stylesheet to add.

```js
import "@nulib/clover/web-components";
```

### Add it to a page

<StartExample />

</div>
</InstallWay>
<InstallWay way="cdn">
<div className="docs-steps">

### Load the script

In the page's `<head>`. The elements bring their own styles, so there is no stylesheet
to add.

```html
<script src="https://cdn.jsdelivr.net/npm/@nulib/clover/dist/web-components/index.umd.js"></script>
```
