# RequiredStatement

<div className="docs-lede">
  The resource's required statement, or the current Canvas's: text that must be
  shown with it, such as an attribution.

## API reference

Reads `requiredStatement` from the Root's resource and renders its label and value as
[`Metadata`](/docs/primitives/metadata) renders a pair, in a description list. It renders
nothing while there is none. Its other props go to the `dl`.

| Prop        | Type                     | Default      | Description                                                           |
| ----------- | ------------------------ | ------------ | --------------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"` | `"manifest"` | Whose statement: the resource's, or the Canvas the reader is on.      |
| `value`     | `{ label, value }`       | —            | A statement to show instead of the Root's. Outside a `Root`, the one. |
| `className` | `string`                 | —            | Added to `clover-required-statement`.                                 |

### A statement of your own

Give it `value` to show a statement you hold, in a `Root` or on its own.

<Example>
<PartDemo
  part="RequiredStatement"
  props={{
    value: {
      label: { en: ["Attribution"] },
      value: {
        en: [
          "Berliner Tageblatt - Staatsbibliothek zu Berlin - Preußischer Kulturbesitz, via Europeana. Public Domain Mark.",
        ],
      },
    },
  }}
/>

```jsx
<Clover.RequiredStatement
  value={{
    label: { en: ["Attribution"] },
    value: {
      en: [
        "Berliner Tageblatt - Staatsbibliothek zu Berlin - Preußischer Kulturbesitz, via Europeana. Public Domain Mark.",
      ],
    },
  }}
/>
```

</Example>
