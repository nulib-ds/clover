# SeeAlso

<div className="docs-lede">
  Descriptions of the resource meant for machines, such as its record as JSON,
  as a list of links.
</div>

<Example>
<PartDemo part="SeeAlso" />

```jsx
<Clover.Root iiifContent={url}>
  <Clover.SeeAlso />
</Clover.Root>
```

</Example>

## API reference

Reads `seeAlso` from the Root's resource and renders a `ul`: a link to each description,
named by its label or else its address, with its `format` after it. It renders nothing
while there is none, and its other props go to the `ul`.

| Prop        | Type                      | Default      | Description                                                      |
| ----------- | ------------------------- | ------------ | ---------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"`  | `"manifest"` | Whose `seeAlso`: the resource's, or the Canvas the reader is on. |
| `value`     | `{ id, label, format }[]` | —            | Descriptions to show instead of the Root's, as IIIF gives them.  |
| `className` | `string`                  | —            | Added to `clover-see-also`.                                      |

## Examples

### Outside a Root

Give it `value`, the descriptions as IIIF gives them, and it needs no `Root`.

<Example>
<PartDemo
  part="SeeAlso"
  props={{
    value: [
      {
        id: "https://api.dc.library.northwestern.edu/api/v2/works/46dc28d1-9d59-4160-a511-72418f70cffc",
        type: "Dataset",
        label: {
          none: ["Northwestern University Libraries Digital Collections API"],
        },
        format: "application/json",
      },
    ],
  }}
/>

```jsx
<Clover.SeeAlso
  value={[
    {
      id: "https://api.dc.library.northwestern.edu/api/v2/works/46dc28d1-9d59-4160-a511-72418f70cffc",
      type: "Dataset",
      label: {
        none: ["Northwestern University Libraries Digital Collections API"],
      },
      format: "application/json",
    },
  ]}
/>
```

</Example>

### Without a label

A description without a label is named by its address. Its address wraps, with
nowhere else to break, rather than pushing the page sideways.

        type: "Dataset",
        format: "application/json",
      },
    ],
  }}
/>
