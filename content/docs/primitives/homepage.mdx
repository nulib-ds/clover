# Homepage

<div className="docs-lede">
  The web pages about the resource, as a list of links.
</div>

<Example>

```jsx
<Clover.Root iiifContent={url}>

```

</Example>

## API Reference

Reads `homepage` from the Root's resource and renders a `ul`: a link to each page, named by
its label or else its address, with its `format` after it. It renders nothing while there
is none, and its other props go to the `ul`.

| Prop        | Type                      | Default      | Description                                                       |
| ----------- | ------------------------- | ------------ | ----------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"`  | `"manifest"` | Whose `homepage`: the resource's, or the Canvas the reader is on. |
| `value`     | `{ id, label, format }[]` | —            | Pages to show instead of the Root's, as IIIF gives them.          |
| `className` | `string`                  | —            | Added to `clover-homepage`.                                       |

## Examples

### Several pages

A resource can have more than one homepage, and each is a link. This film's are on
Wikimedia Commons and in the National Archives Catalog.

<Example>
<PartDemo part="Homepage" resource="footage" />

```jsx
<Clover.Root iiifContent="https://nulib-ds.github.io/clover/mocks/rudolf-hess-nuremberg/manifest.json">
  <Clover.Homepage />
</Clover.Root>
```

</Example>

### Outside a Root

Give it `value`, the pages as IIIF gives them, and it needs no `Root`.

<Example>
<PartDemo
  part="Homepage"
  props={{
    value: [
      {
        id: "https://catalog.archives.gov/id/23769",
        type: "Text",
        label: { en: ["National Archives Catalog"] },
        format: "text/html",
      },
    ],
  }}
/>

```jsx
<Clover.Homepage
  value={[
    {
      id: "https://catalog.archives.gov/id/23769",
      type: "Text",
      label: { en: ["National Archives Catalog"] },
      format: "text/html",
    },
  ]}
/>
```

</Example>
