## API reference

Reads `partOf` from the Root's resource and renders a `ul`: a link to each Collection,
named by its label or else its address. It renders nothing while there is none, and its
other props go to the `ul`. A link opens the Collection's IIIF JSON: to show the
Collection itself, use [`Collection`](/docs/collection).

| Prop        | Type                      | Default      | Description                                                     |
| ----------- | ------------------------- | ------------ | --------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"`  | `"manifest"` | Whose `partOf`: the resource's, or the Canvas the reader is on. |
| `value`     | `{ id, label, format }[]` | —            | Collections to show instead of the Root's, as IIIF gives them.  |
| `className` | `string`                  | —            | Added to `clover-part-of`.                                      |

## Examples

### Outside a Root

Give it `value`, the Collections as IIIF gives them, and it needs no `Root`.

<Example>
<PartDemo
  part="PartOf"
  props={{
    value: [
      {
        id: "https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif",
        type: "Collection",
        label: { none: ["Commedia dell'Arte: The Masks of Antonio Fava"] },
      },
    ],
  }}
/>

```jsx
<Clover.PartOf
  value={[
    {
      id: "https://api.dc.library.northwestern.edu/api/v2/collections/c373ecd2-2c45-45f2-9f9e-52dc244870bd?as=iiif",
      type: "Collection",
      label: { none: ["Commedia dell'Arte: The Masks of Antonio Fava"] },
    },
  ]}
/>
```

</Example>

### Without a label

A Collection without a label is named by its address. Its address wraps, with
nowhere else to break, rather than pushing the page sideways.

<Example>

        type: "Collection",
      },
    ],
  }}
/>

```jsx
<Clover.PartOf
  value={[
    {
      id: "https://api.dc.library.northwestern.edu/api/v2/collections/0ba3a256-4952-44ea-b0d9-0772835ff137?as=iiif",

/>
```

</Example>
