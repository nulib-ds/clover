## API reference

Reads `thumbnail` from the Root's resource and renders an `img`, its `alt` the resource's
label. It renders nothing while there is no picture. Its other props go to the `img`.

<ApiReference elements="clover-thumbnail">

| Prop        | Type                     | Default              | Description                                                        |
| ----------- | ------------------------ | -------------------- | ------------------------------------------------------------------ |
| `of`        | `"manifest" \| "canvas"` | `"manifest"`         | Whose thumbnail: the resource's, or the Canvas the reader is on.   |
| `value`     | IIIF resource            | —                    | A Manifest, Canvas or Collection to picture instead of the Root's. |
| `size`      | `number`                 | `400`                | Pixels asked for on the longer side, and the `img`'s `width`.      |
| `alt`       | `string`                 | The resource's label | The picture's text alternative.                                    |
| `className` | `string`                 | —                    | Added to `clover-thumbnail`.                                       |

</ApiReference>

## Examples

### The current Canvas

Use `of="canvas"` for the Canvas in view. This newspaper's pages have no `thumbnail`, so
each is pictured by the image it paints.

<Example>
<PartDemo
  part="Thumbnail"
  props={{ of: "canvas", size: 200 }}
  resource="page-transcript"
  body
/>

```jsx {3}
<Clover.Root iiifContent="https://nulib-ds.github.io/clover/mocks/page-transcript/manifest.json">
  <Clover.Body />
  <Clover.Thumbnail of="canvas" size={200} />
</Clover.Root>
```

</Example>

### Beside its title

Beside a `Label` that says the same, use `alt=""`, so assistive technology does not read
the title twice.

<Example>
<PartDemo
  parts={[
    { part: "Thumbnail", props: { alt: "", size: 200 } },
    { part: "Label", props: { as: "h4" } },
  ]}
  row
/>

```jsx
<Clover.Thumbnail alt="" size={200} />
<Clover.Label as="h4" />
```

</Example>

### Size and crop

Size it, and crop it, with your CSS: Clover's stylesheet leaves `.clover-thumbnail` alone.

<Example>
<PartDemo
  part="Thumbnail"
  props={{
    style: { width: "16rem", aspectRatio: "16 / 9", objectFit: "cover" },
  }}
/>

```jsx
<Clover.Thumbnail
  style={{ width: "16rem", aspectRatio: "16 / 9", objectFit: "cover" }}
/>
```

</Example>

## Previous versions

[Clover 3.x › Thumbnail](/docs/3.x/thumbnail)

- Inside a `Root`, leave out `thumbnail`: it reads the resource's own.
- Its `alt` is the resource's label: no `altAsLabel`.
- `objectFit` is `object-fit`, in your CSS.
- It is always an `img`: no video thumbnails.
