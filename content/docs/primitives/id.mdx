## API reference

Reads `id` from the Root's resource and renders an `a` to it, the address as its text. For
a Manifest, that is where its IIIF JSON is. The link is underlined, and a long address
wraps rather than pushing the page sideways. It renders nothing while there is none, and
its other props go to the `a`.

| Prop        | Type                     | Default      | Description                                                 |
| ----------- | ------------------------ | ------------ | ----------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"` | `"manifest"` | Whose `id`: the resource's, or the Canvas the reader is on. |
| `value`     | `string`                 | —            | An address to show instead of the Root's.                   |
| `className` | `string`                 | —            | Added to `clover-id`.                                       |

## Examples

### The current Canvas

Use `of="canvas"` for the address of the Canvas in view. It changes as the reader moves.

<Example>
<PartDemo part="Id" props={{ of: "canvas" }} content />

```jsx
<Clover.Content />
<Clover.Id of="canvas" />
```

</Example>

### Outside a Root

Give it `value`, an address, and it needs no `Root`.

<Example>

  props={{

  }}

```jsx
<Clover.Id value="https://nulib-ds.github.io/clover/mocks/tagging/manifest.json" />
```

</Example>
