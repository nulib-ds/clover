# Metadata

<Callout type="info">
  Looking for the Metadata of Clover 3.x, `@samvera/clover-iiif`? It is at
  [Clover 3.x › Metadata](/docs/3.x/metadata).
</Callout>

The Manifest's `metadata`, or the current Canvas's with `of="canvas"`: each label and
value pair, in the reader's language, in a description list. Outside a `Root`, give it the
pairs to show as `value`.

```jsx
import * as Clover from "@nulib/clover";

<Clover.Root iiifContent={manifestUrl}>
  <Clover.Label as="h2" />
  <Clover.Metadata />
</Clover.Root>;
```

## What it renders

A `dl`. Each pair is a `div` round its `dt`, the label, and its `dd`, the value, which
keeps the two associated for assistive technology.

```html
<dl class="clover-metadata">
  <div data-label="date">
    <dt>Date</dt>
    <dd>1896</dd>
  </div>
</dl>
```

- Each `div`'s `data-label` is its label in lower case, hyphens for spaces
  (`alternate-title`). It is read in `none`, else the label's first language, so it stays
  the same whatever the reader's language: a hook for your CSS.
- Labels and values carry the language they are in as `lang`; those in `none` carry none.
  A language's several values are joined with commas.
- A value is shown as IIIF's limited HTML, sanitized, when it runs from a first `<` to a
  last `>` (see [HTML](/docs/primitives#html)); otherwise as written. Links in it are
  underlined, not only colored, and long unbroken values wrap.
- Without metadata it renders nothing.

## Values of your own

`renderValue` is called with each pair, `{ label, value }`. Return what its `dd` should
hold, or `undefined` to keep Clover's. Here each subject links to a search of your own, for
a record whose labels and values are in `none`, as the catalog's are:

```jsx
import React from "react";
import * as Clover from "@nulib/clover";

function renderValue(item) {
  if (item.label.none?.[0] !== "Subject") return undefined;
  return (item.value.none ?? []).map((subject, index) => {
    const href = `/search?subject=${encodeURIComponent(subject)}`;
    return (
      <React.Fragment key={subject}>
        {index > 0 && ", "}
        <a href={href}>{subject}</a>
      </React.Fragment>
    );
  });
}

<Clover.Metadata renderValue={renderValue} />;
```

A `dd` you fill carries no `lang`: mark text in a language other than the page's yourself.
`renderValue` is called while `Metadata` renders, so it calls no hooks; to use them (to read
a value with `useLocalized`, say), return an element of a component of your own.

## Props

| Prop          | Type                     | Description                                                 |
| ------------- | ------------------------ | ----------------------------------------------------------- |
| `of`          | `"manifest" \| "canvas"` | Whose metadata. Default `manifest`.                         |
| `value`       | `{ label, value }[]`     | Pairs to show instead of the Root's.                        |
| `renderValue` | `(item) => ReactNode`    | A value of your own; Clover's where it returns `undefined`. |
| `className`   | `string`                 | Added to `clover-metadata`.                                 |

It takes no `as`: it is a `dl`. Its other props (`id`, `style`, `aria-*`) go to the `dl`.

### Styles

`.clover-metadata` stacks its pairs `--clover-space-s` apart, each label over its value, in
the text's color and size. Labels are medium weight (500); values keep the text's own.

## From Clover 3.x

| 3.x `Metadata`                                    | Clover 4                                                                                        |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `metadata`                                        | `value`; inside a `Root`, leave it out                                                          |
| `customValueContent`: `matchingLabel`, `Content`  | `renderValue(item)`: match `item.label`, return the content                                     |
| `customValueDelimiter`                            | Not in Clover 4: a language's values are joined with commas. `renderValue` joins them otherwise |
| `as` (`dl`)                                       | Always a `dl`                                                                                   |
| `lang`                                            | The Root's `language`; outside a `Root`, the page's `<html lang>`, then the browser's           |
| `className`, `style`, `title`, `data-*`, `aria-*` | The same, on the `dl`                                                                           |

Each pair keeps its `div` with `data-label`, as in 3.x.
