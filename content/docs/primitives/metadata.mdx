## API reference

Reads `metadata` from the Root's resource and renders a description list, each label a
`dt` and each value a `dd`. A value may be IIIF's [HTML](/docs/primitives#html). It
renders nothing while there is no metadata. Its other props go to the `dl`.

<ApiReference elements="clover-metadata">

| Prop          | Type                     | Default      | Description                                                      |
| ------------- | ------------------------ | ------------ | ---------------------------------------------------------------- |
| `of`          | `"manifest" \| "canvas"` | `"manifest"` | Whose metadata: the resource's, or the Canvas the reader is on.  |
| `value`       | `{ label, value }[]`     | —            | Pairs to show instead of the Root's. Outside a `Root`, the ones. |
| `renderValue` | `(item) => ReactNode`    | —            | A value of your own; Clover's where it returns `undefined`.      |
| `className`   | `string`                 | —            | Added to `clover-metadata`.                                      |

</ApiReference>

### Values of your own

`renderValue` is called with each pair: return what its `dd` holds, or `undefined` for
Clover's. Here each subject links to a search. A value you render carries no `lang`, so
mark one in another language yourself.

```jsx
import { Fragment } from "react";

function renderValue(item) {
  if (item.label.none?.[0] !== "Subject") return undefined;
  return (item.value.none ?? []).map((subject, index) => (
    <Fragment key={subject}>
      {index > 0 && ", "}
      <a href={`/search?subject=${encodeURIComponent(subject)}`}>{subject}</a>
    </Fragment>
  ));
}

<Clover.Metadata renderValue={renderValue} />;
```

```html twin
<clover-metadata></clover-metadata>

<script type="module">
  document.querySelector("clover-metadata").renderValue = (item) => {
    if (item.label.none?.[0] !== "Subject") return undefined;
    const subjects = document.createDocumentFragment();
    (item.value.none ?? []).forEach((subject, index) => {
      if (index > 0) subjects.append(", ");
      const link = document.createElement("a");
      link.href = `/search?subject=${encodeURIComponent(subject)}`;
      link.textContent = subject;
      subjects.append(link);
    });
    return subjects;
  };
</script>
```

## Previous versions

[Clover 3.x › Metadata](/docs/3.x/metadata)

- `metadata` is now `value`; inside a `Root`, leave it out.
- `customValueContent` is `renderValue`.
- A language's values are joined with commas: no `customValueDelimiter`.
- 3.x's `lang` is the Root's `language`.
