## API Reference

Reads `rendering` from the Root's resource and renders a `ul`: a link to each format, named
by its label or else its address, with its `format` after it. It renders nothing while
there is none, and its other props go to the `ul`. [`Download`](/docs/download) offers the
view's and the resource's behind one button.

| Prop        | Type                      | Default      | Description                                                        |
| ----------- | ------------------------- | ------------ | ------------------------------------------------------------------ |
| `of`        | `"manifest" \| "canvas"`  | `"manifest"` | Whose `rendering`: the resource's, or the Canvas the reader is on. |
| `value`     | `{ id, label, format }[]` | —            | Formats to show instead of the Root's, as IIIF gives them.         |
| `className` | `string`                  | —            | Added to `clover-rendering`.                                       |

## Examples

### The current Canvas

Beside a `Content`, `of="canvas"` lists the formats of the Canvas in view, and changes as
the reader moves. Each page of this newspaper links its own text.

<Example>
<PartDemo
  part="Rendering"
  resource="page-transcript"
  props={{ of: "canvas" }}
  content
/>

```jsx
<Clover.Content />
<Clover.Rendering of="canvas" />
```

</Example>

### Outside a Root

Give it `value`, the formats as IIIF gives them, and it needs no `Root`.

<Example>
<PartDemo
  part="Rendering"
  props={{
    value: [
      {
        id: "https://nulib-ds.github.io/clover/mocks/rudolf-hess-nuremberg/transcript.txt",
        type: "Text",
        label: { en: ["Transcript in plain text format"] },
        format: "text/plain",
      },
    ],
  }}
/>

```jsx
<Clover.Rendering
  value={[
    {
      id: "https://nulib-ds.github.io/clover/mocks/rudolf-hess-nuremberg/transcript.txt",
      type: "Text",
      label: { en: ["Transcript in plain text format"] },
      format: "text/plain",
    },
  ]}
/>
```

</Example>
