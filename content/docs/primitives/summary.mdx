## API reference

Reads `summary` from the Root's resource, as plain text or IIIF's
[HTML](/docs/primitives#html), and renders a `p`. Past five lines it is cut short, with a
Read more button under it. It renders nothing while there is no summary. Its other props
go to its element.

<ApiReference elements="clover-summary">

| Prop        | Type                     | Default      | Description                                                         |
| ----------- | ------------------------ | ------------ | ------------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"` | `"manifest"` | Whose summary: the resource's, or the Canvas the reader is on.      |
| `value`     | language map or `string` | —            | A summary to show instead of the Root's. Outside a `Root`, the one. |
| `as`        | element type             | `"p"`        | The element to render.                                              |
| `className` | `string`                 | —            | Added to `clover-summary`.                                          |

</ApiReference>

## Examples

### Lines

Set `--clover-summary-lines` on it, or on anything around it, for more or fewer lines than
five; `none` shows it whole. Read more opens it in full, and Read less cuts it short again.

<Example>
<PartDemo part="Summary" props={{ style: { "--clover-summary-lines": "1" } }} />

```jsx
<Clover.Summary style={{ "--clover-summary-lines": 1 }} />
```

</Example>

### The current Canvas

Use `of="canvas"` for the summary of the Canvas in view, as this photogravure's plate has.

<Example>
<PartDemo
  part="Summary"
  props={{ of: "canvas" }}
  resource="tagging"
  body
/>

```jsx {3}
<Clover.Root iiifContent="https://nulib-ds.github.io/clover/mocks/tagging/manifest.json">
  <Clover.Body />
  <Clover.Summary of="canvas" />
</Clover.Root>
```

</Example>

### Text of your own

`ReadMore` gives text of your own the same button. Wrap one element, and clamp it in your
CSS while it is not `data-read-more="open"`.

```jsx
<Clover.ReadMore>
  <p className="my-note">{note}</p>
</Clover.ReadMore>
```

```html twin
<clover-read-more>
  <p class="my-note">…</p>
</clover-read-more>
```

```css
.my-note:not([data-read-more="open"]) {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}
```

## Previous versions

[Clover 3.x › Summary](/docs/3.x/summary)

- `summary` is now `value`; inside a `Root`, leave it out.
- It renders a `p` by default, not a `span`.
- Long summaries are cut short, with Read more.
- 3.x's `lang` is the Root's `language`.
