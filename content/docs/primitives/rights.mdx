## API Reference

Reads `rights` from the Root's resource and renders a link to it, the address as its
text. It renders nothing while there is none. Its other props go to the `a`.

| Prop        | Type                     | Default      | Description                                                          |
| ----------- | ------------------------ | ------------ | -------------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"` | `"manifest"` | Whose rights: the resource's, or the Canvas the reader is on.        |
| `value`     | `string`                 | —            | An address to link instead of the Root's. Outside a `Root`, the one. |
| `className` | `string`                 | —            | Added to `clover-rights`.                                            |

## Examples

### Under a heading

The link's text is the address, as the property gives it, so place it where its context
says what it is, as the [Panel](/docs/panel)'s About section does.

<Example>
<Fragment key="rights">
<h4>Rights</h4>
<PartDemo part="Rights" />
</Fragment>

```jsx
<h4>Rights</h4>
<Clover.Rights />
```

</Example>

### An address of your own

Give it `value` to link an address you hold, in a `Root` or on its own.

<Example>
<PartDemo
  part="Rights"
  props={{ value: "http://creativecommons.org/publicdomain/mark/1.0/" }}
/>

```jsx
<Clover.Rights value="http://creativecommons.org/publicdomain/mark/1.0/" />
```

</Example>
