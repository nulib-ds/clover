# Label

<Callout type="info">
  Looking for the Label of Clover 3.x, `@samvera/clover-iiif`? It is at [Clover
  3.x › Label](/docs/3.x/label).
</Callout>

The Manifest's `label`, or the current Canvas's with `of="canvas"`, in the reader's
language. It renders a `span`, or with `as` a heading, a paragraph or any other element.
Outside a `Root`, give it the label to show as `label`; inside one, a `label` you give wins
over the Root's.

```jsx
import * as Clover from "@nulib/clover";

<Clover.Root iiifContent={manifestUrl}>
  <Clover.Label as="h1" />
  <Clover.Content />
  <Clover.Label of="canvas" as="p" />
</Clover.Root>;
```

## Text and language

- A label is plain text: tags are dropped, and entities such as `&amp;` decoded.
- It is read in the Root's `language`, else the page's, else the browser's (see
  [Languages](/docs/primitives#languages)). A language's several values are joined with
  commas.
- It carries the language it is in as `lang`, so assistive technology reads it in that
  language. A label in `none` carries no `lang`, and takes the page's.
- It renders nothing while there is no label: before the Manifest loads, or for a resource
  without one.

## Headings

`Label` is a heading only when `as` makes it one, and its level is yours: give it the level
that fits the page's outline, `as="h2"` under the page's `h1`. `.clover-label` balances its
lines (`text-wrap: balance`), so a long title breaks into lines of about one length rather
than leaving a word alone on the last. Its size and weight are your layout's.

## Props

| Prop        | Type                     | Description                                                         |
| ----------- | ------------------------ | ------------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"` | Whose label. Default `manifest`.                                    |
| `label`     | language map or `string` | A label to show instead of the Root's. Outside a `Root`, the label. |
| `as`        | element type             | Default `span`.                                                     |
| `className` | `string`                 | Added to `clover-label`.                                            |

Its other props (`id`, `style`, `aria-*`) go to its element, and so does its `ref`.

## From Clover 3.x

| 3.x `Label`                                       | Clover 4                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `label`                                           | `label`; inside a `Root`, leave it out                                                |
| `as`                                              | `as`, any element                                                                     |
| `lang`                                            | The Root's `language`; outside a `Root`, the page's `<html lang>`, then the browser's |
| `className`, `style`, `title`, `data-*`, `aria-*` | The same                                                                              |

Without `lang`, 3.x showed a label's first entry; Clover 4 shows the one closest to the
reader's language.
