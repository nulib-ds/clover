## API reference

Reads `label` from the Root's resource, as plain text, and renders a `span`. It renders
nothing while there is no label. Its other props, and its `ref`, go to its element.

<ApiReference elements="clover-label">

| Prop        | Type                                                                                                                                            | Default      | Description                                                                                                                                                             |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `of`        | `"manifest" \| "canvas"`                                                                                                                        | `"manifest"` | Whose label: the resource's, or the current Canvas's.                                                                                                                   |
| `label`     | language map or `string`                                                                                                                        | —            | A label to show instead of the Root's. Outside a `Root`, the one.                                                                                                       |
| `as`        | `"h1"` \| `"h2"` \| `"h3"` \| `"h4"` \| `"h5"` \| `"h6"` \| `"span"` \| `"label"` \| `"figcaption"` \| `"p"` \| `"strong"` \| `"em"` \| `"div"` | `"span"`     | The element to render: a heading at your page's level, whose size is your page's for that level; a name for something; or text. In React, any element or component too. |
| `className` | `string`                                                                                                                                        | —            | Added to `clover-label`.                                                                                                                                                |

</ApiReference>

## Examples

### As a heading

Use `as` to make it a heading, at the level that fits your page's outline: here, under an
`h3`, an `h4`.

<Example>
<PartDemo part="Label" props={{ as: "h4" }} />

```jsx
<Clover.Label as="h4" />
```

</Example>

### The current Canvas

Use `of="canvas"` for the label of the Canvas in view. It changes with the current Canvas.

<Example>
<PartDemo part="Label" props={{ of: "canvas", as: "p" }} body />

```jsx
<Clover.Body />
<Clover.Label of="canvas" as="p" />
```

</Example>

### In its own language

A label is read in the Root's `language`, else the browser's languages, and carries the language it is
in as `lang`, so it is read aloud in that language. This newspaper's label is German.

<Example>
<PartDemo part="Label" props={{ as: "p" }} resource="search" />

```jsx {2}
<Clover.Root iiifContent="https://clover.iiif.library.northwestern.edu/mocks/content-search/manifest.json">
  <Clover.Label as="p" />
</Clover.Root>
```

</Example>
