## API reference

Shows `value` in the reader's language, read by its `format`, and renders a `span`. Its
HTML is sanitized to what IIIF allows. It reads nothing from the Root's resource, renders
nothing while there is no text, and its other props go to its element.

| Prop           | Type                     | Default     | Description                                                   |
| -------------- | ------------------------ | ----------- | ------------------------------------------------------------- |
| `value`        | language map or `string` | —           | The text, as IIIF gives it: `{ en: ["…"] }`.                  |
| `format`       | `string`                 | IIIF's rule | `text/html`, `text/markdown`, or any other, shown as written. |
| `headingLevel` | `number`                 | `3`         | With Markdown, its first heading's level.                     |
| `as`           | element type             | `"span"`    | The element to render: a `div` for paragraphs and lists.      |
| `className`    | `string`                 | —           | Added to `clover-value`.                                      |

## Examples

### Plain text

Use `format="text/plain"` to show a value as written, tags and all, its line breaks kept.

<Example>
<PartDemo
  part="Value"
  props={{
    value: { en: ["Plates pair <i>Then</i> with <i>Now</i>."] },
    format: "text/plain",
  }}
/>

```jsx
<Clover.Value
  value={{ en: ["Plates pair <i>Then</i> with <i>Now</i>."] }}
  format="text/plain"
/>
```

</Example>

### Markdown

Use `format="text/markdown"` for Markdown: its lists are lists, and its headings headings,
the first at `headingLevel`. Here, under an `h3`, that is 4.

<Example>
<PartDemo
  part="Value"
  props={{
    value: {
      en: [
        "# The White bicycles\n\nIssued in 1896 by the **White Sewing Machine Company**.\n\n## Plates\n\n- Thulstrup\n- Mente\n- Veenfliet\n- Clarke",
      ],
    },
    format: "text/markdown",
    headingLevel: 4,
    as: "div",
  }}
/>

```jsx
const description = {
  en: [
    `# The White bicycles

Issued in 1896 by the **White Sewing Machine Company**.

## Plates

- Thulstrup
- Mente
- Veenfliet
- Clarke`,
  ],
};

<Clover.Value
  value={description}
  format="text/markdown"
  headingLevel={4}
  as="div"
/>;
```

</Example>

### Without a format

With no `format`, IIIF's rule decides: a value is HTML when it runs from a first `<` to a
last `>`, as this one does, and is shown as written otherwise.

<Example>
<PartDemo
  part="Value"
  props={{
    value: { en: ["<p>Plates pair <i>Then</i> with <i>Now</i>.</p>"] },
    as: "div",
  }}
/>

```jsx
<Clover.Value
  value={{ en: ["<p>Plates pair <i>Then</i> with <i>Now</i>.</p>"] }}
  as="div"
/>
```

</Example>
