## API reference

Inside a `Root`, it reads the view's WebVTT captions and any transcript as plain text,
with a choice where there are several, and renders nothing where there is neither.
`Default` and `Document` show it in their [Panel](/docs/panel). Its other props, and its
`ref`, go to its element.

<ApiReference elements="clover-transcript">

| Prop        | Type         | Default | Description                                         |
| ----------- | ------------ | ------- | --------------------------------------------------- |
| `follow`    | `boolean`    | `true`  | Keep the cue playing in view while the media plays. |
| `as`        | element type | `"div"` | The element to render, such as a `section`.         |
| `className` | `string`     | —       | Added to `clover-transcript`.                       |

</ApiReference>

## Examples

### Scroll in a box

Give it a height, and it scrolls in a box of its own. Make the box a named region the
keyboard can reach, as here (WCAG 2.1.1).

<Example>
<PartDemo
  part="Transcript"
  resource="footage"
  body
  props={{
    as: "section",
    "aria-label": "Transcript",
    tabIndex: 0,
    style: { maxHeight: "20rem", overflowY: "auto" },
  }}
/>

```jsx
<Clover.Transcript
  as="section"
  aria-label="Transcript"
  tabIndex={0}
  style={{ maxHeight: "20rem", overflowY: "auto" }}
/>
```

```html twin
<!-- The element is a box no reader is told of: the page's own region names and scrolls it. -->
<section
  aria-label="Transcript"
  tabindex="0"
  style="max-height: 20rem; overflow-y: auto"
>
  <clover-transcript></clover-transcript>
</section>
```

</Example>

### Leave the scrolling to the reader

Use `follow={false}` to leave the scrolling to the reader. The cue playing is still
marked.

<Example>
<PartDemo
  part="Transcript"
  resource="transcripts"
  body
  props={{
    follow: false,
    as: "section",
    "aria-label": "Transcript",
    tabIndex: 0,
    style: { maxHeight: "20rem", overflowY: "auto" },
  }}
/>

```jsx
<Clover.Transcript follow={false} />
```

</Example>

### A transcript of your own

Clover's WebVTT parser is exported: `parseVtt` reads a file's cues, and `cueAt` finds the
one playing.

```js
import { cueAt, parseVtt } from "@nulib/clover";

const cues = parseVtt(await (await fetch(vttUrl)).text());
const index = cueAt(cues, video.currentTime);
const words = index >= 0 ? cues[index].text : "";
```
