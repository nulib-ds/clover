## API reference

Use Map on its own with `iiifContent`, or inside a `Root`, where it maps the Root's
resource and follows the view. The map itself is [MapLibre GL](https://maplibre.org/),
which loads the first time a map comes into view.

Map shows two kinds of IIIF data. A resource's
[navPlace](https://iiif.io/api/extension/navplace/) holds its places as GeoJSON, which
show as points, lines or areas. [Georeference Extension](https://iiif.io/api/extension/georef/)
annotations pin images to the ground, and Map lays each one over the map. Under the map, Items lists
each place and image. Choose one to zoom to it; inside a `Root`, its Canvas opens too.

Each place shows its own `label`, or the label of the Manifest, Canvas or member it
belongs to, with that resource's `navDate` when it has one. Its picture is that resource's
`thumbnail`, else its first image. In a
Collection, choosing a member's place opens that member's Manifest.

Its other props, and its `ref`, go to its element.

### Georeferenced images

A [Georeference Extension](https://iiif.io/api/extension/georef/) annotation pins an
image to the ground with control points: spots on the image matched to spots on the map.
Clover fits the image to those points and trims it to its mask, the part of the image that
is map. Set `overlayOpacity` to see the streets underneath. The image server must allow
cross-origin requests (CORS), since the image is painted onto the map.

In the [Canvas](/docs/canvas), a georeferenced Canvas gets a Map control even without a
[navPlace](https://iiif.io/api/extension/navplace/). It opens a small map with the image
laid over it, and Expand map puts the map in the Canvas's place until you press it again
or close the map.

### Georeferencing multiple items

Give `iiifContent` a georeference annotation, or an AnnotationPage or AnnotationCollection
of them, as Allmaps and other georeferencing tools publish them. Clover opens the Manifest
each annotation's target is `partOf` and lays the map on its Canvas. When the target has no
Manifest, or the Manifest can't be fetched, Clover shows each image the annotations target
as a Canvas of its own. The Viewer, a `Root` and a `Canvas` on its own all open them this
way.

With georeference annotations as the content, a Root's maps show every sheet at once and
outline the one in view. That includes the Panel's map and the Canvas's own. Set
`overlays="view"` on a `Map` to show only the view's.

Clover fits each image the way its annotation asks: `helmert` (scale, rotation and shift)
from two or more control points, and otherwise a first-order `polynomial` (affine) from
three or more. Higher orders and thin plate splines use the affine fit.

This example is the Sanborn Fire Insurance Maps of Evanston, Illinois, from 1920: sheets
from downtown through Northwestern University's campus and along the lake, in one
AnnotationPage. Point at a sheet to find it in the list. Choose one, in the list or on the
map, and the map zooms to it.

### Customize layout

Map lists its places and images under itself with Items, in any of Items' layouts. To put
the list somewhere else, set `items` to `false` and give the page a list of your own. That
list then does the map's list's job: it is the map in words, and how a keyboard reaches
each place.

Inside a `Root`, `Items` with `of="georeferences"` lists the georeferenced images, each
pictured as its map. With `overlays="all"`, the map shows every sheet, not only the one in
view. Choose a sheet, in `Items` or on the map, and its Canvas opens and the map zooms to
it. Point at a sheet in either, and both highlight it.

The example at the top of this page is built this way. Its sheets' targets have no Manifest, so the
`Root` reads the AnnotationPage's own `label` and `summary` as a Manifest's, and `Label`
and `Summary` show them.

To build the list yourself, read the sheets with `georeferencesOf` and reach the map
through the `Root`. To choose a sheet, call `clover.goTo` with its Canvas; the map outlines
the sheet on the Canvas in view. To point at one, emit its id on `clover.highlight`; the
map outlines it at half strength, and emits the sheet under the pointer in return.

```jsx react
import { useSyncExternalStore } from "react";
import * as Clover from "@nulib/clover";
import "@nulib/clover/styles.css";

/** One sheet: chosen, it opens its Canvas; pointed at, it lights on the map. */
function Sheet({ sheet, current, pointed }) {
  const { clover } = Clover.useClover();
  const name = Clover.useLocalized(sheet.label);
  const point = (id) => clover.highlight.emit(id);
  return (
    <li>
      <button
        type="button"
        aria-current={current ? "true" : undefined}
        data-pointed={pointed || undefined}
        onClick={() => clover.goTo(sheet.canvasId)}
        onMouseEnter={() => point(sheet.id)}
        onMouseLeave={() => point(null)}
        onFocus={() => point(sheet.id)}
        onBlur={() => point(null)}
      >
        <span lang={name.lang}>{name.text}</span>
      </button>
    </li>
  );
}

/** Every georeferenced sheet of the Root's resource. */
function SheetList() {
  const { clover } = Clover.useClover();
  const manifest = Clover.useManifest();
  const sheets = Clover.georeferencesOf(manifest);
  const canvas = Clover.useActiveCanvas();
  // The sheet pointed at, here or on the map.
  const pointed = useSyncExternalStore(
    clover.highlight.subscribe,
    clover.highlight.get,
  );
  return (
    <ul>
      {sheets.map((sheet) => (
        <Sheet
          key={sheet.id}
          sheet={sheet}
          current={sheet.canvasId === canvas?.id}
          pointed={sheet.id === pointed}
        />
      ))}
    </ul>
  );
}

export default function Atlas() {
  return (
    <Clover.Root iiifContent="https://clover.iiif.library.northwestern.edu/mocks/sanborn/annotation-page.json">
      <Clover.Map overlays="all" items={false} />
      <SheetList />
    </Clover.Root>
  );
}
```

### In a layout of your own

Inside a `Root`, the map shows the georeferenced images of the Canvases in view, and
choosing a place opens its Canvas. When an annotation tags a place on part of a Canvas,
such as a map printed on a page (Cookbook 0139), choosing the place selects that
annotation, and the Canvas zooms to its region.

```jsx
import * as Clover from "@nulib/clover";

<Clover.Root iiifContent={url}>
  <Clover.Body />
  <Clover.Map />
</Clover.Root>;
```

### Size

Set the map's height with `--clover-map-height` (`24rem` by default), not `height`:
`style` goes to the box around both the map and its list.

```jsx
<Clover.Map iiifContent={url} style={{ "--clover-map-height": "420px" }} />
```

### MapLibre's worker

Clover bundles MapLibre's worker and starts it from a `blob:` URL, so maps work in any
bundler with no setup. If your Content Security Policy blocks `blob:` workers
(`worker-src`), serve the worker yourself and tell Clover where it is, once for every map.
Until then, the map says it can't be shown, and the console says how to fix it.

```js
import { setMapWorkerUrl } from "@nulib/clover";

// maplibre-gl-worker.mjs and maplibre-gl-shared.mjs, copied together from
// node_modules/maplibre-gl/dist/ to a folder you serve.
setMapWorkerUrl("/static/maplibre-gl-worker.mjs");
```

The worker must match the MapLibre that Clover depends on. A page that brings its own
MapLibre serves that version's worker the same way; Clover says so in the console.
