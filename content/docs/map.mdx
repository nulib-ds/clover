## API reference

Draws a resource's [navPlace](https://iiif.io/api/extension/navplace/) places and its
[georeferenced](https://iiif.io/api/extension/georef/) images on a
[MapLibre GL](https://maplibre.org/) map, and lists them under it. MapLibre loads when a
map is first shown. Inside a `Root`, it maps the Root's resource and follows the view; its
other props, and its `ref`, go to its element.

<ApiReference elements="clover-map">

| Prop             | Type                              | Default          | Description                                                |
| ---------------- | --------------------------------- | ---------------- | ---------------------------------------------------------- |
| `iiifContent`    | `string \| object`                | —                | On its own: a resource to map. In a `Root`, leave it out.  |
| `navPlace`       | `object`                          | —                | GeoJSON to draw: a FeatureCollection, Feature or geometry. |
| `georeferences`  | `object[]`                        | —                | Georeference Extension annotations to lay over the map.    |
| `overlay`        | `boolean`                         | `true`           | Draw the georeferenced images.                             |
| `overlayOpacity` | `number`                          | `0.75`           | Their opacity, from 0 to 1.                                |
| `styleUrl`       | `string`                          | Clover's basemap | A MapLibre style, used as it is.                           |
| `workerUrl`      | `string`                          | Clover's own     | Where MapLibre's worker is served from, to serve your own. |
| `scrollZoom`     | `boolean`                         | `false`          | Zoom with the wheel or trackpad.                           |
| `onSelect`       | `(feature) => void`               | —                | A place was chosen, on the map or in its list.             |
| `request`        | `{ credentials, headers, fetch }` | —                | With `iiifContent`: for every request.                     |
| `language`       | `string`                          | The reader's     | With `iiifContent`: the language to read IIIF text in.     |
| `as`             | element type                      | `"div"`          | The element to render.                                     |
| `className`      | `string`                          | —                | Added to `clover-geomap`.                                  |

</ApiReference>

## Examples

### Georeferenced images

A Georeference Extension annotation lays its image over the map by an affine fit of its
control points, clipped to its mask. The image server must allow CORS.

<Example>
<MapDemo mock="georeference/manifest.json" />

```jsx
<Map iiifContent="https://nulib-ds.github.io/clover/mocks/georeference/manifest.json" />
```

</Example>

### In a Viewer

The Viewer adds a Map section to its Panel by itself, where the resource has places or a
georeference.

<ViewerExample resource="map">

```jsx
<Viewer iiifContent="https://nulib-ds.github.io/clover/mocks/georeference/manifest.json" />
```

</ViewerExample>

### In a layout of your own

Inside a `Root`, it lays the view's georeferenced images over the map, and choosing a
place goes to its Canvas.

```jsx
import * as Clover from "@nulib/clover";
import { Map } from "@nulib/clover/map";

<Clover.Root iiifContent={url}>
  <Clover.Body />
  <Map />
</Clover.Root>;
```

### Size

Size the map with `--clover-map-height` (default `24rem`), never `height`: `style` goes
to the box around the map and its list.

```jsx
<Map iiifContent={url} style={{ "--clover-map-height": "420px" }} />
```

### MapLibre's worker

Clover brings MapLibre's worker, bundled, and starts it from a `blob:` URL, so a map draws
its places in any bundler with no setup. A page whose Content Security Policy refuses
`blob:` workers (`worker-src`) serves the worker itself, and tells Clover where, once,
for every map.

```js
import { setMapWorkerUrl } from "@nulib/clover";

// maplibre-gl-worker.mjs and maplibre-gl-shared.mjs, copied together from
// node_modules/maplibre-gl/dist/ to a folder you serve.
setMapWorkerUrl("/static/maplibre-gl-worker.mjs");
```

The worker is the one built for the MapLibre Clover depends on. A page that brings
another MapLibre serves that one's worker the same way; Clover says so in the console.
