## API reference

Draws a resource's [navPlace](https://iiif.io/api/extension/navplace/) places and its
[georeferenced](https://iiif.io/api/extension/georef/) images on a
[MapLibre GL](https://maplibre.org/) map, and lists them under it. MapLibre loads when a
map is first shown. Inside a `Root`, it maps the Root's resource and follows the view: a
Collection's members too, each opening its Manifest as it is pressed. A place is named with the
date of what it locates (its `navDate`), in its list and on the map, and on the map with
its picture: its Manifest's, Canvas's or member's `thumbnail`, else its first image. Its other props, and
its `ref`, go to its element.

### Georeferenced images

A Georeference Extension annotation lays its image over the map by an affine fit of its
control points, clipped to its mask, opaque unless `overlayOpacity` says otherwise. The
image server must allow CORS.

In the [Canvas](/docs/canvas), a georeferenced Canvas has a Map control even without a

<span data-code-flavor="both">`navPlace`</span>: it opens a map with the image
laid over it, and its Expand map button puts the map in the Canvas's place until
it is pressed again or closed.

### Georeferencing multiple items

Give `iiifContent` a georeference annotation on its own, or an AnnotationPage or
AnnotationCollection of them, as Allmaps and other georeferencing tools publish them.
Each one is laid on the Canvas it targets, in the Manifest its target names, where the
map draws it. Where the target names no Manifest, or its Manifest cannot be fetched, the
images it targets are shown, each as a Canvas of its own. The Viewer, a `Root` and a
`Canvas` on its own open them the same way, and the Canvas's Map control lays each map
over the ground.

Given them as the content, a `Root`'s maps, the Panel's and the Canvas's own too, lay
every sheet, the one in view outlined; set `overlays="view"` on a `Map` for the view's
alone.

Each image is laid by the fit its annotation asks for: `helmert` (scale, rotation and
shift) from two control points or more, and otherwise a first-order polynomial (affine)
from three or more. A higher order or a thin plate spline is drawn by the affine fit.

These are the Sanborn Fire Insurance Maps of Evanston, Illinois, from 1920, from downtown
through Northwestern University's campus and along the lake, each sheet georeferenced by
machine, in one AnnotationPage. Point at a sheet to find it in the list. Choose one, in the
list or on the map, and the map zooms to it and outlines it.

### Customize layout

The map lists its places and georeferenced images under it, through Items, in any of
Items' layouts. Set `items` to `false` to list none and put a list of your own wherever your
layout wants it. That list is then the map's text and the keyboard's way to each place, so
a page that turns the map's own list off must give one.

Inside a `Root`, `Items` lists the georeferenced images with `of="georeferences"`, each
pictured as the map it is. `overlays="all"` lays every sheet on the map, not only the
Canvas's in view. Choose a sheet, in `Items` or on the map, and the view goes to its Canvas
and the map zooms to it; point at one, and it lights in both.

The example at the top of this page is laid out so. Its sheets name no Manifest, so the
`Root` reads the AnnotationPage's own `label` and `summary` as a Manifest's, and `Label`
and `Summary` introduce them.

To list them your own way, read them with `georeferencesOf` and reach the map through the
`Root`. To choose a sheet, go to its Canvas with `clover.goTo`; the map outlines the sheet
on the Canvas in view. To point at one, emit its id on `clover.highlight`; the map outlines
it at half strength, and emits the sheet under the pointer there in turn.

```jsx react
import { useSyncExternalStore } from "react";
import * as Clover from "@nulib/clover";
import "@nulib/clover/styles.css";

/** One sheet: chosen, it opens its Canvas; pointed at, it lights on the map. */
function Sheet({ sheet, current, pointed }) {
  const { clover } = Clover.useClover();
  const name = Clover.useLocalized(sheet.label);
  const point = (id) => clover.highlight.emit(id);
  return (
    <li>
      <button
        type="button"
        aria-current={current ? "true" : undefined}
        data-pointed={pointed || undefined}
        onClick={() => clover.goTo(sheet.canvasId)}
        onMouseEnter={() => point(sheet.id)}
        onMouseLeave={() => point(null)}
        onFocus={() => point(sheet.id)}
        onBlur={() => point(null)}
      >
        <span lang={name.lang}>{name.text}</span>
      </button>
    </li>
  );
}

/** Every georeferenced sheet of the Root's resource. */
function SheetList() {
  const { clover } = Clover.useClover();
  const manifest = Clover.useManifest();
  const sheets = Clover.georeferencesOf(manifest);
  const canvas = Clover.useActiveCanvas();
  // The sheet pointed at, here or on the map.
  const pointed = useSyncExternalStore(
    clover.highlight.subscribe,
    clover.highlight.get,
  );
  return (
    <ul>
      {sheets.map((sheet) => (
        <Sheet
          key={sheet.id}
          sheet={sheet}
          current={sheet.canvasId === canvas?.id}
          pointed={sheet.id === pointed}
        />
      ))}
    </ul>
  );
}

export default function Atlas() {
  return (
    <Clover.Root iiifContent="https://clover.iiif.library.northwestern.edu/mocks/sanborn/annotation-page.json">
      <Clover.Map overlays="all" items={false} />
      <SheetList />
    </Clover.Root>
  );
}
```

### In a layout of your own

Inside a `Root`, it lays the view's georeferenced images over the map, and choosing a
place goes to its Canvas. A place an annotation tags on part of a Canvas (a map on a page,
Cookbook 0139) is that annotation too: choosing it selects it, and the Canvas frames its
region.

```jsx
import * as Clover from "@nulib/clover";

<Clover.Root iiifContent={url}>
  <Clover.Body />
  <Clover.Map />
</Clover.Root>;
```

### Size

Size the map with `--clover-map-height` (default `24rem`), never `height`: `style` goes
to the box around the map and its list.

```jsx
<Clover.Map iiifContent={url} style={{ "--clover-map-height": "420px" }} />
```

### MapLibre's worker

Clover brings MapLibre's worker, bundled, and starts it from a `blob:` URL, so a map draws
its places in any bundler with no setup. A page whose Content Security Policy refuses
`blob:` workers (`worker-src`) serves the worker itself, and tells Clover where, once,
for every map. Until it does, the map says it could not be shown, and the console says
how.

```js
import { setMapWorkerUrl } from "@nulib/clover";

// maplibre-gl-worker.mjs and maplibre-gl-shared.mjs, copied together from
// node_modules/maplibre-gl/dist/ to a folder you serve.
setMapWorkerUrl("/static/maplibre-gl-worker.mjs");
```

The worker is the one built for the MapLibre Clover depends on. A page that brings
another MapLibre serves that one's worker the same way; Clover says so in the console.
